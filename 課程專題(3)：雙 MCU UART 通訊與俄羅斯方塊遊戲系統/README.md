## 專題概覽

微處理機實習的期末專題。以兩片 Arduino Uno 透過 **UART 序列通訊分工**，做出可計分、計時的 8×8 LED 點矩陣俄羅斯方塊。因為單板腳位與算力不足，把系統拆成兩個各自即時運作的子系統，只在必要時同步。

- **分工**：兩人一組。**全部韌體由本人負責**（遊戲邏輯、跨板通訊協定、各周邊模組驅動、系統整合與除錯）；組員負責報告與影片。

## 系統架構

- **Board A（主控板）**：執行遊戲邏輯，驅動 8×8 LED 點矩陣、I2C LCD 1602（分數與歷史紀錄）、搖桿（類比 X／Y 軸＋按鍵）與蜂鳴器。
- **Board B（計時板）**：以 `millis()` 累計遊戲時間，多工掃描驅動 4 位七段顯示器。
- **通訊**：UART 9600 bps，RX／TX 交叉對接。主控板送出 `S`（開始計時）、`P`（暫停並回傳時間）、`R`（歸零），遊戲結束時以握手取回時間，判定是否刷新最佳紀錄。

## 設計重點

- **非阻塞主迴圈＋有限狀態機**：以計時判斷取代 `delay()`，畫面更新、搖桿讀取與雙板通訊在同一迴圈並行。
- **位元運算節省記憶體**：ATmega328P 僅 2 KB SRAM，方塊旋轉狀態預先建表（約 112 bytes），盤面以位元表示（8 bytes），碰撞與消行都用位元運算。
- **除錯經驗**：解決 Uno 的 Pin 0／1 與 USB 共用序列埠造成的上傳衝突，以及重複接地形成迴路導致的重置與亂碼；並加入緩衝區清空與逾時保護。
